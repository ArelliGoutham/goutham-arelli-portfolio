# Goutham Arelli Portfolio

Vercel-deployable portfolio for Goutham Arelli.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
```

## Deploy

Import this repository into Vercel.

Default build command:

```bash
npm run build
```

The output is handled by Next.js.

## Phase 2

After the first deployment, add:

- `public/llms.txt`
- `public/sitemap.xml`
- optional `public/llms-full.txt`
